# Gudu 的个人博客

目前只实现 Hero 首屏：包豪斯几何、深色太空、左上两行标题与实时日期时间、接近侧视的倾斜黑洞特写，以及鼠标视差。页面仅保留标题和时钟文字。

宽屏桌面的标题与黑洞共享居中的构图区域，最大宽度为首屏实际高度的 16/9；黑洞尺寸也按该高度封顶。超宽屏两侧延伸星空背景，避免黑洞随屏幕宽度持续放大。手机端保留独立的竖屏布局。

## 线上访问

[打开 Gudu 的个人博客](https://gudu.blog/)

GitHub Pages 从 `main` 分支的根目录发布，推送更新后自动部署。`.nojekyll` 让页面和静态资源直接发布。

## 本地预览

需要 Node.js 18 或更新版本，无需安装依赖：

```sh
npm run dev
```

打开 http://localhost:4173 。也可以直接打开 `index.html`，所有视觉资源均在本地，不依赖 CDN。

## 结构

- `index.html`：语义结构及文字。
- `css/style.css`：首屏布局、桌面与移动端适配。
- `js/black-hole.js`：WebGL 光线积分、吸积盘着色与泛光。
- `js/horizon-transition.js`：黑洞阴影点击、双向白色冲击与扇形反色切换。
- `js/main.js`：本地时钟、星空、视差与动画生命周期。
- `js/loading.js`：加载幕布、资源就绪检测与超时放行。
- `assets/fonts/`：背景标题 `GUDU’s` 使用本地 Barlow Condensed Black。字体及 SIL Open Font License 均随网站提供，不依赖在线字体服务。

## 黑洞视觉

吸积盘倾角为 81°，指盘面法线与视线的夹角，盘面接近侧视。画面中的斜向构图单独控制，两者相互独立。

着色器在三维空间积分 Schwarzschild 光线轨迹，捕获进入视界的光线，并计算光线与薄吸积盘的交点。因此阴影、透镜像和高阶细环由光路形成。盘内缘为 3 倍 Schwarzschild 半径；轨道速度、多普勒频移与引力红移共同影响颜色及亮度。使用暖金与奶油白色板，以多尺度流动纹理形成长短、疏密不同的细丝；对强高光做柔和压缩，保留亮侧的纹理与明暗差。细纹根据实际渲染像素的覆盖范围逐级过滤，采样导数统一在光线追踪结束后计算，减少视差移动时的摩尔纹。外缘逐渐淡出至透明，泛光集中于较亮的区域；合成时平滑高反差边缘，并抑制阴影内部的泛光。这些材质与合成处理保留原有光路和透镜结构。

这是用于实时网页的有限步长可视化，颜色经过艺术处理，不是完整的 Kerr 黑洞或科学辐射转移模拟。物理形态参考 [NASA 黑洞可视化](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/) 与 [NASA 黑洞结构](https://science.nasa.gov/universe/black-holes/anatomy/)。

动画自动播放，并遵循系统减少动态效果偏好；页面不可见时停止绘制。支持分辨率自适应，以及 WebGL 不可用或上下文丢失时的静态插画回退。仅渲染首屏内可见的画面，以保持清晰度并避免绘制屏幕外的区域。移动端不拦截触摸滚动。

光子环附近使用局部 4×4 子像素光线采样，同时平均颜色与透明度，改善细环在视差移动中的闪烁。额外采样沿用原有光线积分和盘面遮挡，不叠加人工圆环；前方吸积盘保留普通材质采样。没有跨帧累积，以避免移动拖影。

时钟采用访问者设备的本地时区，每秒读取真实时间；与视觉动画独立更新，返回页面时立即校时。

标题在首次展示时分层入场：背景英文浮现、中文沿水平边界揭开、橙色句点最后落位，总时长约 0.9 秒。英文、中文与时钟使用不同幅度的鼠标视差；移动端保留入场，系统减少动态效果偏好下直接显示最终排版。入场结束或离开页面后不重复播放。

开场加载页使用极简金色轨道与橙色方点，等待字体和黑洞首帧（或静态备用图）就绪后淡出，再开始标题入场。动画为不定进度提示，不显示虚构百分比；正常情况下至少展示 0.6 秒，淡出用时 0.42 秒，最迟在 4 秒时放行。关闭 JavaScript 时直接显示页面；资源失败、后台切换和减少动态效果偏好均有对应处理。

点击黑洞阴影内部可切换全页反色：白色冲击沿垂直于吸积盘的两个方向喷发，再展开成扇面，逐步覆盖整个窗口，约 1.7 秒完成。再次点击同一区域可切回原色。命中检测沿用黑洞光线路径，排除前景吸积盘；移动端支持点按，拖动不触发。键盘可用 Tab 聚焦黑洞中的“反色主题”按钮，以 Enter 或空格切换。系统减少动态效果偏好下直接切换；窗口调整、滚动或切后台时立即完成当前过渡。反色作用于实际合成画面，包含文字、星空和黑洞，刷新后回到默认深色。
