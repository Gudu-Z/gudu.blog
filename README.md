# Gudu 的个人博客

使用原生前端的静态个人博客，沿用极简科技风与深色太空首屏：两行标题、实时日期时间，以及暖白与淡琥珀色的实时 WebGL 黑洞。成组细线随盘面流动，鼠标控制相机视角，背景仅保留稀疏星点。首屏之后依次是自我介绍、分类、最新文章和归档，支持移动端导航、RSS 订阅和完整的文章阅读页。Markdown 和 YAML 只在构建时解析，浏览器不加载这些依赖。

目前等待作者提供真实文章，因此文章和归档展示待更新状态，没有填充示例文章、虚构统计或不可用的社交链接。搜索入口保持可用，尚无文章时显示真实空状态；加入文章后，分类、文章计数与分页会自动启用。

宽屏桌面的标题与黑洞共享居中的构图区域，最大宽度为首屏实际高度的 16/9；黑洞尺寸也按该高度封顶。超宽屏两侧延伸星空背景，避免黑洞随屏幕宽度持续放大。手机端保留独立的竖屏布局。

## 线上访问

[打开 Gudu 的个人博客](https://gudu.blog/)

GitHub Pages 从 `main` 分支的根目录发布，推送更新后自动部署。`.nojekyll` 让页面和静态资源直接发布。

## 本地预览

需要 Node.js 20.19 或更新版本。首次使用或依赖锁定文件更新后，先执行 `npm ci`：

```sh
npm ci
npm run dev
```

打开 http://localhost:4173 。也可以直接打开 `index.html`，所有视觉资源均在本地，不依赖 CDN。

预览服务器支持 RSS、站点地图和自定义 404。内容修改后先运行 `npm run build`；仅修改 HTML/CSS/JS 时刷新页面即可。

## 首页章节

向下滚动或滑动即可从主视觉整段切入自我介绍，回到主视觉时也采用整段切换；键盘方向键、Page Down、空格和“跳到主要内容”链接也能进入。主视觉底部不再显示介绍文字与“向下探索”入口。黑洞在约 900 毫秒内缩至原构图的 34%、移到画面正中心并消除画面滚转，俯仰保持与主视觉一致（极简 81°、水墨 83°），首屏文字退场。远景盘面材质能量提高 18%，极简主题增加取自吸积盘自身光线的局部柔光，不提高背景底色或星空亮度。WebGL 2 复用已有盘面辉光纹理的 mipmap，所有绘制仍纳入现有 GPU 完成检测与预算；WebGL 1 保留基础辉光。半透明黑色直角面板（88% 不透明，黑洞只隐约透出）通过阴影分层，不描外框，只保留极淡的 1px 细边、顶部细高光和左上、右下两个定位角标；角标画在背景层上，不占用面板到位时的点亮装饰。分类、最新文章和归档的标题使用同一字重与字距，末尾统一为首屏“个人博客”后的橙色方块。面板之间保持固定间距，当前章节右侧能露出下一章的一部分。顶部工具栏和黑白灰仪表盘在进入内容区后出现。顶部透明悬浮，左侧保留 Logo 与双行站点文字，右侧提供搜索框与 RSS，中央留空；按回车或点击搜索会切到最新文章显示结果，并保留顶部输入焦点，文章面板不再重复放置搜索框。底部承担章节导航与位置提示，以水平基线和竖向分隔刻度串起关于、分类、最新文章、归档四个区域，当前区域白色点亮。

首屏切入使用一条约 900 毫秒的时间线：标题与时钟错开退场，完整面板从右侧接入，关于区的编号与头像先显现，标题、读音、档案字段和个人链接随后错开展开，右侧入口卡片逐层接入；内容层在同一切换进度的 96% 前完成，返回 Hero 时按同一坐标反向收起，不新增计时器或动画帧循环。顶部 Logo、站名和副标先依次显现，校准细线展开、橙色短线轻亮，搜索和 RSS 再错开就位，RSS 两道弧线分别描出；顶部在约 720 毫秒时完成，切换全程保持不可聚焦，搜索框沿用原有展开交互。顶部与内容共用可反向的切换进度，底部基线与刻度同步逐层出现。黑洞在中段短暂增加局部辉光，峰值为已有辉光的 1.3 倍，随后恢复；背景和星空不参与这一脉冲，也不增加渲染通道。返回主视觉约 680 毫秒，界面收起后标题恢复。直接访问章节链接不播放启动动画，章节之间继续平滑横移；面板保持固定透明度，文字保留独立的错层入场和退场动画，停稳后短暂点亮细线与编号。面板与其外部标题共用画面中心的透视视点，按近→远→近的轨迹运动：每张平面连接同一弧面上的左右端点，旋转、纵深和尺寸由这两个端点统一确定，靠近边缘时充分侧转并放大，大面板也不会被单独压低倾角。各端点保持在阅读平面前方，并维持相邻边缘的顺序；弧面仅在整张面板出画后截断并继续向外延伸。仅实际内容过长的区域启用原生纵向滚动，并按未变换的正文高度限制阅读范围，避免透视投影制造额外空白；滚动容器额外保留横向投影空间；窄屏文章主卡与下方半宽卡之间留出 32px 纵向间距，避免不同深度的面板相碰。窗口缩放、隐藏页面或开启减少动态效果时会完成当前导航并清除装饰状态，离开页面时停止动画。

滚动更新只使用一条动画链：已同步绘制的位置不再由随后到达的 scroll 事件重复更新。面板直接更新自身 transform，进度变量限制在底部导航内；未变化的样式、class 和 inert 不重复写入。游标通过 transform 移动，窗口重测先集中读取几何再写入布局。黑洞光线积分复用上一步终点的加速度，保持原有步长、光路与分辨率；静止视差图层和备用星空也不再随黑洞每帧重绘。自动检查记录这些路径的工作量，并比较光线结果的一致性；它们不替代真实设备的帧率测量。

顶部搜索平时只显示图标，鼠标悬停或键盘聚焦时向左展开；触屏可点击图标打开。展开后用同一个放大镜或回车提交搜索，不再显示重复的文字按钮。输入期间保持展开，鼠标与焦点均离开后收起，Esc 可关闭并返回图标焦点。

底部使用精密刻度样式，以长分隔与暗色短刻度区分层级；宽屏按比例细分刻度，细刻度约 20px、中刻度约 80px 一根，与 1440px 屏幕相近，并始终对齐站点。游标（白色三角、橙色竖线）连续跟随横移，到达每章时停在该格中央。当前章节从本站竖线到下一站之间的整段横轴白色亮起。切换章节时，光从游标穿过的那根竖线进入新的一格，旧的一格同时收回到这根竖线，向左移动时方向相反；进出首屏时随横轴一起从左向右展开。悬停或聚焦其他站名时，该段直接淡入。鼠标经过横轴时，点击落点处显示一条细竖线，附近刻度提亮，对应站名也稍微变亮。点击或松手的位置离某章中心不到一格宽度的十分之一时，停到该章中央，其余位置保持原样；拖动过程中不吸附。滑动时游标带轻微光晕。静止约 1 秒后，游标光晕以 4 秒周期轻缓呼吸，当前区域的三个短刻度每 9 秒依次亮起一次，扫光过程约 0.8 秒。导航只用黑白灰，暖橙色 `#f06446` 只用在游标竖线上。滚动、导航和触摸期间停止循环，停下后重新等待；循环由 CSS 驱动，不增加持续的 JavaScript 定时器或动画帧。用鼠标或触屏操作完标尺后，焦点交还页面（之前已用 Tab 选中游标时仍留在游标上），Page Down、空格和方向键保持原来的移动方向；用 Tab 选中游标时按滑块操作：方向键移动 1/20 章，Page Up / Page Down 移动一章，Home / End 到首尾，空格不滚动页面。手机上标尺只保留中文站名、横轴和游标，不显示编号和英文副标题，高度更矮，省出的空间留给内容区。页面离开或隐藏时清理反馈，系统减少动态效果时保留位置指示与静态橙色点缀并关闭装饰动画。

进入与离开首屏采用分段切换；内容章节之间，滚轮的距离连续映射为面板从右向左的移动，不逐章吸附。背景与上下导航保持固定，点击导航可平滑抵达指定章节。长内容在章节内部保留原生竖向滚动，到边界后继续横移；手机可左右拖动轨道，上下滑动阅读长面板，同一竖向阅读手势不被中途打断。章节链接保留搜索参数，支持直接访问 `#about`、`#series`、`#journal`、`#archive` 及浏览器返回。系统减少动态效果时跳过缓动并保留连续位置控制；WebGL 不可用时回退图也会缩小、提亮、转平和居中。关闭 JavaScript 后保留正常文档流和锚点导航。

分类、最新文章和归档的内部细节随横向滚动产生轻微视差：轨道与路径装饰最多偏移 12px，标签、编号、年份和日期使用更小幅度，正文与链接整体保留原有位置；手机上限为 5px。每个章节到达导航对应的阅读位置时，内部偏移归零。视差叠加在原有文字显隐与面板透视之内，不改变外部标题的所属平面；文章列表更新后自动继承，不需要重新注册动画。它复用现有滚动帧与缓存，不新增持续动画循环，纵向阅读不会带动横向视差；减少动态效果、页面隐藏和离开时归零。

鼠标在内容区内移动时，整个界面分为前景仪表与后方内容两个视觉深度：顶部工具栏和底部刻度条同步跟随，最大横向 8px、纵向 5px；所有面板连同文字、图片和外部标题一起平移，最大横向 6px、纵向 3.75px，以较小幅度表现位于仪表后方。层内间距与原有透视不变，鼠标经过空白、顶部和底部时也连续响应，离开窗口后缓缓归位；原来的装饰独立鼠标偏移已取消。三个界面容器复用现有更新帧，停稳后停止请求动画帧。按下按钮、编辑搜索框或拖动游标时固定当前偏移，刻度条的点击坐标计入实际位移，拖动期间保持游标与鼠标对齐；滚动和页面退出会清理效果，触屏、窄屏与减少动态效果模式关闭此视差。

首页的鼠标指针换成对焦框：四个角标围着一个白点，略微拖后跟随。移到链接、按钮或卡片上时，角标展开并锁定到目标外 5px，角标长度随目标大小在 6–12px 之间变化，白点变成橙色；底部站名框住它所在的整段标尺。按下时对焦框收紧 3px、白点放大。顶部搜索作为一个整体：放大镜、输入框和清除按钮共用一个对焦框，并随搜索框展开和收起；在输入框里换成系统文字光标，对焦框仍围着搜索框，页面滚动时这个锁定保持不变。经过刻度条横轴时，对焦框收成 10px 宽的卡尺，夹住横轴自己的落点细竖线（包括靠近章节中心时的吸附位置）；悬停或拖动刻度条游标时，对焦框围住它的三角和竖线，拖动时不拖后。按住鼠标期间保持按下时的状态：点击横轴不会跳到远处的游标，真正拖动后才切换为围住游标；点击后的缓动期间卡尺停在落点上。顶部和底部仪表不随页面滚动，滚动时保持锁定，只有不在拖动中的游标被滚走时才松开。这三处由文字光标、细竖线和游标本身指示位置，白点隐藏。第一次移动鼠标前保留系统光标，触屏、触控笔和粗指针设备不启用；减少动态效果时不拖后、不过渡。锁定后的对焦框只在鼠标移动后的 0.4 秒内随视差重读目标位置，目标或其外层的过渡结束时再读一次；页面滚动时，内容区里的锁定先松开，停稳 120 毫秒后再判断鼠标下的元素，不在滚动的每一帧强制布局。文章页保留系统光标。

内容还共用轻微的观察角度变化：鼠标控制水平 ±1.5°、垂直 ±0.8° 的视角，旋转插在统一透视投影内，面板与框外文字继续处于各自所属的同一平面；上下仪表保持前景平移。原有弧面轨迹与布局间距保留，面板不增加厚度或外框。左上方固定光源根据面板与视角合成后的法线决定柔和反射与背光暗部，仅作用于边缘的静态渐变层，不改变正文或背景亮度。角度和光照与平移共用缓动、冻结和退出清理，使用已有面板几何缓存，不增加布局读取或持续动画循环。

## 结构

- `index.html`：首屏、关于与相关入口、文章列表、按年归档和页脚；文章与归档标记之间的内容由构建器生成。
- `css/style.css`：首屏布局、桌面与移动端适配。
- `css/blog.css`：博客内容、导航、阅读页、404 与移动端适配。
- `css/chapters.css`：首页横向面板、固定场景、顶部导航与底部仪表盘。
- `css/categories.css`：四列分类面板（手机为 2×2），列间以细线分隔。每列顶部是 `//` 与英文标签，下方带角标和点阵的取景框里是一件线框标本：Minecraft 是方块，白日梦话是三道大圆组成的球，神秘文案是三张立着的卡片，其他是八面体。四件标本同一视角、同样 1px 线条，脚下是同一块向四周淡出的透视网格地面。悬停或键盘聚焦时镜头微转、标本浮起，再各自展开并亮出一处橙色细节：方块拆成爆炸视图，中心生成橙色核心；球的三道圆环像陀螺仪一样以三种速度散开，一颗橙色卫星开始绕行；卡片像手牌一样展开，前卡的打码文字逐行写出，停在橙色光标；八面体的三个方框各自在平面内转动，重组成立方体的三个中截面，中心亮起橙色节点。离开时所有部件同时归位，减少动态效果时直接到位；取景框变小时标本分档缩小。取景框下是横排名称、两行简介，以及文章数与“浏览”同行的页脚。面板到位时，除面板自身的点亮装饰外，四条标题线也依次点亮；高度不超过 820px 的屏幕收紧间距，使面板完整显示在刻度条上方。全部动画由 CSS 过渡完成，不需要脚本。
- `css/cursor.css`、`js/cursor.js`：首页的对焦框鼠标指针，锁定链接与卡片，仅在精确指针设备上启用。
- `js/main.js`：本地时钟、相机输入、标题视差与实时渲染生命周期。
- `js/chapters.js`：首屏双向分段切换、连续横向滚动、触摸与键盘控制、锚点历史、进度与黑洞转场同步。
- `js/black-hole-theme.js`：首帧前选择极简或水墨主题，配置特殊日期，解析预览链接，并同步主题描述与回退图。
- `js/black-hole.js`：当前首页的 WebGL 黑洞渲染器，提供极简光线积分渲染，以及使用极坐标水墨材质的三维盘面光线追踪。
- `js/particle-sky.js`：极简星空的三维粒子、连续透视运动及用于透镜采样的方向光照纹理。
- `js/ink-splatter.js`：水墨主题的三维点墨粒子，随盘面单向转动，并被主体遮挡。
- `assets/black-hole-minimal.png`：保留的极简构图参考图，记录细线疏密与平衡明暗。
- `assets/black-hole-minimal-fallback.png`：由当前实时着色器画面导出的静态回退图，供 JavaScript 或 WebGL 不可用时显示。
- `assets/black-hole-ink-fallback.png`：水墨实时材质的静态回退图，供水墨主题下 WebGL 不可用时显示。
- `assets/black-hole-ink-reference.png`：第一版水墨原图，仅供离线材质烘焙使用。
- `assets/black-hole-ink-material.png`：从原图提取的极坐标水墨材质图集，供实时水墨渲染加载。
- `assets/black-hole-ink-light.png`：与水墨材质配套的固定明暗图，让笔触流动时保持整体光照构图。
- `assets/black-hole-static.png`：2026 年 10 月 4 日金色旧版的静态图，保留供历史版本回退。
- `js/loading.js`：加载幕布、资源就绪检测与超时放行。
- `js/blog.js`：移动导航、文章搜索、分类筛选、每页 6 篇加载更多、筛选 URL 与浏览器前进后退。
- `js/article.js`：阅读进度、当前章节目录提示、复制链接与失败反馈。
- `content/posts/*.md`：文章编辑入口，开头为 YAML 信息，后接 Markdown 正文；兼容 `.markdown` 和旧 `.json` 文件，目前没有正式文章。
- `content/post-template.md`：可复制的草稿模板，放在文章目录之外，不会参与构建。
- `scripts/markdown.mjs`：构建时解析 Markdown、生成标题目录并提取摘要与阅读时长所用的文本。
- `scripts/build-blog.mjs`：校验文章并生成阅读页、首页静态列表、`js/posts-data.js`、RSS、sitemap、robots 和 404。
- `scripts/bake-ink-material.mjs`：通过本地预览和已启动的 Chrome 调试连接，手工烘焙水墨材质与明暗图。

## 添加真实文章

将 `content/post-template.md` 复制到 `content/posts/`，例如 `content/posts/my-first-story.md`，然后修改开头的信息和正文。一个文件就是一篇文章，不需要按分类建子目录。

```markdown
---
title: 文章标题
slug: my-first-story
date: 2026-10-29
category: 白日梦话
tags:
  - 故事
draft: false
---

这里是文章开头，直接写正文，空一行就是下一段。

## 一个章节

可以使用 **加粗**、*斜体*、[链接](https://gudu.blog/)，也可以写列表：

- 第一项
- 第二项

> 这里是一段引用。
```

- 开头两行 `---` 之间是 YAML 信息，必须包含 `title`、`date`、`category`。值包含冒号加空格等 YAML 特殊字符时请加引号，例如 `title: "观察记录： 一个梦"`。
- `slug` 使用小写英文字母、数字和连字符，对应 `posts/my-first-story.html`，应保持稳定且全站唯一。省略时取文件名去掉扩展名并转为小写；中文文件名需要显式填写英文 `slug`。
- 日期使用有效的 `YYYY-MM-DD`；文章按日期倒序排列，相同日期按 slug 排序。阅读时长根据正文估算。
- `excerpt` 可选，填写时作为首页卡片、搜索和 RSS 的摘要，并显示在文章页标题下方。省略时自动提取第一段文字，最多约 160 个字符；没有段落则从正文提取；自动提取的摘要不会重复显示在文章页标题下。`tags` 是可选列表，也可以写成 `tags: [故事, 记录]`。
- 分类统一配置在 `content/categories.json`：`Minecraft` → `minecraft`、`白日梦话` → `daydreams`、`神秘文案` → `collected`、`其他` → `other`。文章的 `category` 填写对应显示名称；其他名称会保留在文章中，并归入“其他”筛选。标签可自行填写。
- 四个分类始终可选，包括暂时没有文章的分类。分类入口会清空旧搜索词，使用 `?category=minecraft#journal` 这样的稳定链接进入文章区；刷新和前进后退可恢复筛选。分类计数来自已构建的非草稿文章，不受当前搜索影响。
- 搜索匹配标题、摘要、分类和标签，可与分类同时使用。构建会把分类配置和文章元数据一并写入 `js/posts-data.js`，修改配置或文章后需重新运行 `npm run build`。
- `draft: true` 的文章不生成阅读页，也不出现在首页、归档、RSS 或站点地图中。它不是定时发布功能，准备好后改为 `false` 再构建。
- 正文支持标题、加粗、斜体、删除线、链接、图片、嵌套列表、引用、代码块、分隔线和表格。二、三级标题自动生成目录，重复标题会生成不同锚点；只有普通段落的文章也能正常发布。文章标题由开头信息生成，正文建议从 `##` 开始；正文的 `#` 会按二级标题显示。
- 图片建议放在 `assets/posts/` 下，例如 `![图片说明](/assets/posts/my-first-story/scene.webp)`。链接与图片也可使用 HTTPS 地址。相对路径按生成后的 `/posts/文章名.html` 解析，不是相对于 Markdown 源文件；站内图片推荐使用以 `/assets/` 开头的路径。
- 原始 HTML 作为文字显示，不执行脚本；普通 Markdown 排版无需写 HTML。表格和长代码块在窄屏内可横向滚动。
- 旧 JSON 文章仍可继续构建，字段沿用 `slug/title/excerpt/date/category/tags/draft/sections`。`sections` 至少一章，章节含 `title` 与 `blocks`，支持 `paragraph/list/quote/callout/code`。迁移时用同一 `slug` 的 Markdown 替换旧文件，不要同时保留两个同名网址。

写好后执行：

```sh
npm run build
npm run check
```

然后刷新本地预览；尚未启动预览时执行 `npm run dev`。构建会同步首页列表、分类数量、归档、文章上下篇、RSS 与站点地图。删除源文章或将其改为草稿后重新构建，对应的旧生成页也会移除；手写页面不会被清理。不要手工编辑 `posts/*.html`、`js/posts-data.js` 或首页 `posts` / `archive` 标记区域，下次构建会重新生成这些内容。

GitHub Pages 直接发布仓库内的静态文件，因此部署时需要一并提交源文章和生成结果。关闭 JavaScript 后，已发布的文章列表、归档和正文仍然可读。RSS 地址为 [gudu.blog/feed.xml](https://gudu.blog/feed.xml)。

## 黑洞视觉

首页采用实时 WebGL 3D 黑洞渲染，默认保持极简主题。`js/black-hole.js` 按相机方向积分光线，生成倾斜吸积盘、中心暗影及弯曲光弧；暖白与淡琥珀色的细线成组聚散并持续流动。鼠标位置参与相机参数，盘面与光弧会随实际观察方向变化。背景使用稀疏星点及光线偏折，不绘制银河带。着色器采用有限步长的视觉近似，重点是构图、空间关系与动态效果。

极简星空全部由 `js/particle-sky.js` 中 24,000 颗固定种子的三维粒子组成，每颗星保存真实 XYZ 坐标、物理尺寸与亮度。外观参照 10 月 4 日初版星空：采用相同的冷灰白色 `rgb(193, 204, 223)`，以细小星核和暗背景留白为主。距离连续分布，近星自然有更明显的透视、鼠标视差和漂移。相机在星群中沿右上方向平移，星点因此向左下移动，保持当前 1.50 倍活动时间系数；运动复用场景活动时钟，鼠标只添加观察位置偏移。离屏、后台及减少动态效果时暂停。星群在大范围内逐颗循环，边界完全淡出后才换位，没有全景时间重置或刻意的明暗闪动。

粒子使用一个 GPU 点精灵批次投影到方向光照纹理；前方分配更多角度分辨率，仍保留完整球面供强偏折光线采样。星空纹理在初始化时按绘制宽度选用 1024×1024 或 2048×2048，含 mipmap 分别约占 5.3 或 21 MiB，顶点缓冲只上传一次。接缝留有余量并复制边缘星点；收小较亮星的物理半径，使用单层紧实高斯星核，取消额外光晕，保留亚像素重建过滤与能量补偿。光线采样使用解析纹理梯度、mipmap，以及支持时最高 4 倍各向异性过滤，减轻闪烁并保留透镜拉伸星像的细边。

极简背景直接使用积分得到的逃逸方向：取消冲击参数 3.5 到 7 之间混回直线的美术压缩，也取消 `h² > 140` 的直线捷径，避免成像被压缩或在旧阈值产生接缝。吸积盘交点和水墨主题保持既有计算。模型仍使用最多 180 步积分、半径 42 的逃逸边界和无自旋 Schwarzschild 近似；星空仍作为无限远方向背景采样，并非完整的有限距离光源或精确广义相对论模拟。

星群与暗区交错，取消冷暖环境雾光，不绘制银河带；星空的泛光依据覆盖率与光强之差单独抑制，保留不透明吸积盘的泛光。中心阴影与盘面继续遮挡星光，透明盘缘能透出后方背景。标题暗区按实际标题位置计算，水墨主题继续使用原有背景。粒子绘制、过滤及黑洞渲染共用完成检测与绘制预算，退出时统一释放资源。扩展画布保留原来的虚拟相机画框，黑洞的尺寸、位置和俯仰不变。

极简主题的桌面画框统一按首屏实际高度的 1.85 倍设置，中心位于首屏高度的 57%，以宽屏确认的构图为基准；较窄的桌面窗口不再受 1760px 宽度上限影响，也不会在 16:10 分界处突然缩小、下移。窄窗口内横向位置逐渐右移，给标题和吸积盘左端留出空间。画框保持 3:2；平板与手机继续使用各自的尺寸规则。

外缘的暖白薄光适度加宽、提亮，通过柔和光肩融入盘面，近侧亮度更轻。盘边通过覆盖率渐隐，并继续追踪、合成后方光弧，避免暗淡但仍不透明的外层形成黑带；透明过渡集中在最外侧，减少前后细线重叠的区域。俯仰朝扬起方向调整，保持原来的画面倾角。

细线按屏幕两轴的像素频率与实际线宽过滤。可分辨的线条保留覆盖积分；压缩线条使用正值、归一化的 Fejér 核和轻量 Gaussian 滤波，在 0.48 周期/像素前截止，最多计算 16 个谐波并按带宽提前退出。过滤结果不再硬裁切，防止负值振铃被裁切后重新产生高频。发光背景与亮线分别做色调映射，再按覆盖率混合，防止对平均亮度施加非线性曲线而重新制造条纹；极简盘面曝光保持 1.80，亮线核心更清楚，盘面底光与首屏辉光适度减弱。极简中心高阶像和检测到的材质轮廓局部采用八光线采样，水墨保留四光线；子光线跨越不同像层时重新计算对应表面的采样范围。辉光保留先低通再缩小的处理，纹理坐标使用高精度。上述调整不增加渲染通道或全屏多重光线追踪。

极简线束保留原来的数量和疏密分组，叠加轻微、连续的曲率与线宽变化，并在形变进入细线相位前按像素范围过滤。三个局部亮纹沿不同半径旋转，错开淡入、淡出；每段生命周期为 24 秒，完全熄灭后才重置，避免长时间差速旋转把纹理卷成无法分辨的噪点。弧形高光使用四阶谐波过滤，通过递推复用三角函数和指数计算；径向过滤保留总能量，只跳过小于约 0.00004 的远侧尾部，整体明暗分布与局部流动分开。动画继续使用活动时钟，鼠标只影响视角，暂停期间不补算轨道时间。

鼠标视差使用约 110 毫秒时间常数的平滑，标题等轻量图层每次显示刷新都更新。首屏相机仍在跟随输入时，有 GPU 完成检测且未降档的渲染器请求最高 60 帧，静止后回到默认 30 帧；低性能设备继续遵守原有降档与单帧在途限制，不因交互强制降低清晰度。帧调度保留跨刷新的小数余量，兼容 60、75、120、144 Hz；显卡繁忙时保持旧画面，待完成后的下一次刷新绘制当前视角，不消耗空的绘制周期或积压历史鼠标事件。

默认优先使用 WebGL 2，以零超时的 `clientWaitSync` 检查整帧完成信号，不读取 GPU 时间戳。上一帧尚未完成时保留已显示画面并稍后重试，粒子、mipmap 与黑洞共用这一限制；没有计时扩展也不会无条件提交新帧。可见时每次动画回调都检查完成信号，绘制则按独立帧率调度。未完成轮询给出耗时下界，从提交开始到确认完成的时间给出保守上界；使用连续 8 帧的中位数判断负载。暂停、切换主题或超过 250 ms 的轮询间断会清空采样与恢复计时，保留限制提交的 fence。WebGL 1 兼容路径保留计时扩展检测；没有该扩展时使用较低像素预算及帧间隔采样，不根据 JS 提交速度猜测 GPU 恢复能力。

WebGL 2 的渲染宽度最多 3200 像素，设备像素比最多取 2，初始像素预算最多 370 万，可覆盖原生 1080p、1440p 及部分高密度屏幕。WebGL 1 保留 2400 像素宽度、1.5 倍设备像素比，根据计时扩展能力采用 180 万或 90 万预算。所有路径都受设备的 `MAX_TEXTURE_SIZE` 限制。

有 GPU 完成信号或计时扩展时，持续超载会优先降低内部渲染尺寸，保留 30 fps 的目标节奏。每次根据耗时降低 10%–25%，最低为目标尺寸的 60%，调整间隔至少 750 ms；达到下限仍超载，才降至 20、15 fps。确认连续 5 秒有足够余量后，先恢复帧率，再每次恢复 5% 尺寸，恢复间隔至少 2 秒。恢复判断会按下一档像素面积估算耗时，并保留余量，避免反复切档。没有计时能力的 WebGL 1 保留更保守的帧率优先策略。尺寸变化只在上一帧完成后的下一次绘制前生效，尺寸未变时不重新分配纹理；构图、光路与活动时钟的速度保持不变。

内容章节开始横移时，若渲染器已经降低画质或帧率，或上一帧持续繁忙，暂时保留黑洞背景并停止它的动画回调，把 GPU 余量留给面板合成。横移结束后继续绘制，不补算暂停期间的轨道时间；首屏与内容区之间的黑洞相机转场仍正常播放。章节仅在活动开始、类型切换与结束时通知背景，不增加逐帧事件或额外计时器。远景柔光还会跳过光晕范围之外的九次纹理取样，保持原有亮度与分布。

极简与水墨使用按主题专门编译的着色器，编译期常量移除另一主题的光线和材质分支。只在首次选择某个主题时异步编译并缓存，快速切换时串行构建并仅激活最后请求的主题；只访问水墨时不创建粒子星空的程序、几何和图集。关闭、刷新或上下文丢失会取消编译轮询并使旧任务失效。

页面隐藏或场景离屏时暂停持续绘制；首页章节模式下场景固定在视口内，进入内容区后继续绘制。系统减少动态效果偏好下保留静止画面，移动端仅在章节边界接管单指竖向滑动。普通页面退出会取消初始化轮询和绘制重试，并屏蔽迟到回调；关页路径不再调用 WebGL，包括逐项删除 GPU 资源，交由浏览器在销毁文档时回收上下文，避免退出处理再次进入忙碌的显卡驱动。仍在使用的页面若主动销毁渲染器，普通 `dispose()` 继续释放其资源。进入浏览器往返缓存时只暂停，返回后继续。加载器在退出时静默清理，恢复可见后才通知页面就绪；章节布局忽略离开页面后的尺寸变化和迟到通知。WebGL 不可用，或 WebGL 1 缺少着色器导数扩展时，显示当前主题对应的 `assets/black-hole-minimal-fallback.png` 或 `assets/black-hole-ink-fallback.png`，两张图均由对应实时材质画面导出。极简回退图的外围留白做透明渐隐，避免窄屏显示出星空画框的矩形边界。关闭 JavaScript 时显示默认极简回退图。

东方水墨主题使用三维光线追踪：光线与由 `inkHeight` 定义、略有起伏的盘面相交，再读取从原参考图提取的极坐标材质。同一图集的不同通道分别保存前盘、上方光弧与下方副像的笔触；配套明暗图将整体光照分布与流动笔触分开，保留原画的明暗构图。透明盘边继续追踪并合成后方光弧，避免边缘截断产生黑带。盘面飞白与外围三维点墨共同形成不规整的水墨轮廓；这是依据原画制作的视觉重建，不保证像素级复刻或严格的物理模拟。极简模式继续使用原有渲染方式。

水墨笔触和点墨以每秒 0.12 弧度连续单向旋转，约 52.36 秒一周。独立的单调活动时钟推进轨道相位，帧率与鼠标输入不改变转速；隐藏、离屏或减少动态效果时冻结，恢复后不补算暂停时间。水墨鼠标视差保留相机俯仰、画面倾转与平移，取消绕盘面法线的方位角变化，避免观察角变化叠加出转速改变的观感。动画不使用整张参考图的往复形变。

材质通过 mipmap 与 WebGL 2 原生纹理导数采样（WebGL 1 使用 `EXT_shader_texture_lod`）减少压缩笔触的锯齿和闪烁；水墨所需的扩展不可用时显示水墨回退图。运行时同时加载 `assets/black-hole-ink-material.png` 与 `assets/black-hole-ink-light.png`，原图仅用于离线烘焙。

需要从原图重新生成材质时，使用 Node.js 22 或更新版本，先启动本地预览，并准备已开启 Chrome DevTools Protocol（CDP）、调试端口为 9243 的 Chrome/Chromium，再执行：

```sh
node scripts/bake-ink-material.mjs --site http://127.0.0.1:4173 --port 9243
```

脚本读取原参考图与当前渲染器的盘面几何，生成 `assets/black-hole-ink-material.png` 和 `assets/black-hole-ink-light.png`，保留原图不变。它使用已有浏览器连接，不会启动浏览器，也无需安装额外依赖；材质烘焙仅手工执行，不随 `npm run build` 或 `npm run check` 运行。

水墨首屏局部采用近黑炭纸背景、暖白文字与低调纸纹，文章区域和全站导航保持现有样式。直接打开 [水墨预览](http://localhost:4173/?blackhole=ink) 或 [极简预览](http://localhost:4173/?blackhole=minimal)，也可以在部署地址后使用相同参数。有效的 `blackhole=ink` / `blackhole=minimal` 参数优先于日期配置，未知参数值按正常日期规则处理。水墨两张纹理均加载就绪后开始实时绘制；加载期间或任一加载失败时显示水墨回退图。

特殊日期在 `js/black-hole-theme.js` 的 `config` 中设置：

```js
const config = {
  timeZone: 'Asia/Shanghai',
  fixedDates: [],  // 单次日期，填写 YYYY-MM-DD 字符串。
  annualDates: [], // 每年日期，填写 MM-DD 字符串。
};
```

日期按北京时间（`Asia/Shanghai`）判断，与访问者本地时区无关；固定日期或每年日期任一匹配即使用水墨，其他日期使用极简。每年 `02-29` 仅在闰年对应日期生效。目前两个列表均为空，尚未设置自动切换日期。页面每分钟以及恢复可见时重新判断，切换会同步实时材质、回退图与无障碍描述；首次加载在首帧前确定主题。没有额外的页面主题控件。

`assets/black-hole-minimal.png` 及本地风格画廊中的图片作为构图参考保留；水墨原图仅作为上述离线材质烘焙的来源。画廊展示的是静态概念图，可通过其中的首页链接查看实时效果。旧版金色静态图 `assets/black-hole-static.png` 继续保留，原有 `js/black-hole.js` 已改造成当前渲染器。

时钟采用访问者设备的本地时区，每秒读取真实时间；与视觉动画独立更新，返回页面时立即校时。

首屏入场与加载页淡出同时开始：黑洞和星空先渐显，背景英文浮现，中文沿水平边界揭开，时钟、站点标识与导航随后错峰进入，橙色句点和底部提示收尾；整组入场约 1 秒。文字入场与鼠标视差使用独立的变换，黑洞仅渐显，不改变渲染裁切尺寸。移动端保留入场，系统减少动态效果偏好下直接显示最终排版；入场结束或离开页面后不重复播放。

“个人博客”右侧的红色方块在入场结束后按固定 1 秒周期连续闪动：亮 0.5 秒、灭 0.5 秒，由 CSS 动画循环控制。离开首屏、隐藏标签页或启用减少动态效果时暂停并恢复常亮，返回后从亮起状态重新开始。

开场加载页直接使用作者 Logo 的原始 SVG 路径：细白线先从左下向右上加速勾勒斜向部分，再接入顺时针展开、逐渐减速的圆形部分。两段交接重叠 90 毫秒，避免衔接停顿；白色填充沿相同的速度曲线落后轮廓 140 毫秒跟进，约 0.93 秒形成完整标识。橙金色内环晚一点起笔，逆时针加速后柔和收尾，前后两层共用一个揭示遮罩，描边接点放在被 Logo 遮住的右上方；完成后保持纯金色静止，不叠加浅色流光。轮廓与填充复用同一原稿路径，保留 Logo 形状与金环交错层次；SVG 内联于首页，不需要额外下载图片或动画库。下方“正在载入”提示在 0.5 秒后淡入，完整标识至少停留约 0.17 秒后开始退场。

加载页等待字体与黑洞首帧就绪后，保持 Logo 位置和尺寸稳定，整体平滑淡出，用时 0.42 秒；淡出开始即播放首屏入场，不等遮罩完全消失。当前主题回退图同时解码，实时渲染初始化失败时使用它。动画为不定进度提示，不显示虚构百分比；正常情况下自 Logo 动画开始至少展示 1.1 秒。准备过慢时约 3.45 秒启动退场，4 秒强制放行，资源或过渡事件挂起均不会继续锁住页面。关闭 JavaScript 时直接显示页面与回退图；减少动态效果时显示完整静态 Logo、首帧或回退图就绪后直接放行。后台与退出时静默释放，恢复可见后再通知页面。

WebGL 初始化提前到加载幕布期间：先给 Logo 勾勒约 1.1 秒，再编译材质并绘制静止首帧。支持 `KHR_parallel_shader_compile` 时轮询非阻塞的编译完成状态，再读取链接结果与 uniform；提交首帧后通过零等待的 GPU 完成检测通知加载器。正常情况下幕布开始淡出时黑洞即可响应，不再等待标题入场结束。超时先放行回退图，迟到的实时材质仍可替换它；编译失败或上下文丢失时保留静态画面。减少动态效果时准备同样的首帧，但不启动持续动画。

## 检查

```sh
npm run check
```

检查包含 JavaScript 语法、生成文件与文章源的一致性，以及文章生成、主题日期、动画计时、渲染器启动、帧调度和粒子几何的自动化测试。计时测试覆盖慢帧、连续鼠标输入、暂停恢复、分档帧率、加载期间准备首帧与高负载滑动暂停；加载测试覆盖首帧等待、失败回退、软硬超时与页面恢复；启动测试覆盖按需异步编译、快速切换、缓存复用、上下文恢复、编译失败与扩展缺失；渲染测试覆盖零超时完成检测、繁忙时保留画面、资源释放、原生分辨率、优先降低像素成本以及带冷却和保守耗时预测的恢复。提示生成文件过期时，先执行 `npm run build`。测试不向网站添加文章或修改视觉资产。

细线采样检查直接执行着色器中的标量计算，验证多种线宽、像素尺度和方向下的覆盖范围、平均亮度、频谱截止与清晰线条保留，并检查色调映射后的亮度对覆盖率保持线性；局部亮纹检查覆盖生命周期衔接、角度接缝、长时间运行和过滤后的平均亮度。此检查不替代浏览器中的光路导数、浮点精度和最终合成验证。

透镜检查从着色器提取实际光路积分与天空方向变换，在 CPU 上验证旧截断处连续性、完整环状成像、远场偏折、方向旋转，以及盘面遮挡和水墨兼容性。它验证当前模型的行为，不作为精确广义相对论基准。
