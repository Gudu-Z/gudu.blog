# Gudu 的个人博客

无依赖的静态个人博客，沿用极简科技风与深色太空首屏：两行标题、实时日期时间、细线黑洞和鼠标视差。首屏之后是文章、归档、关于与 RSS 订阅入口，支持移动端导航和完整的文章阅读页。

目前等待作者提供真实文章，因此文章和归档展示待更新状态，没有填充示例文章、虚构统计或不可用的社交链接。加入文章后，搜索、分类、文章计数与分页会自动启用。

宽屏桌面的标题与黑洞共享居中的构图区域，最大宽度为首屏实际高度的 16/9；黑洞尺寸也按该高度封顶。超宽屏两侧延伸星空背景，避免黑洞随屏幕宽度持续放大。手机端保留独立的竖屏布局。

## 线上访问

[打开 Gudu 的个人博客](https://gudu.blog/)

GitHub Pages 从 `main` 分支的根目录发布，推送更新后自动部署。`.nojekyll` 让页面和静态资源直接发布。

## 本地预览

需要 Node.js 18 或更新版本，无需安装依赖：

```sh
npm run dev
```

打开 http://localhost:4173 。也可以直接打开 `index.html`，所有视觉资源均在本地，不依赖 CDN。

预览服务器支持 RSS、站点地图和自定义 404。内容修改后先运行 `npm run build`；仅修改 HTML/CSS/JS 时刷新页面即可。

## 结构

- `index.html`：首屏、文章列表、按年归档、关于和页脚；文章与归档标记之间的内容由构建器生成。
- `css/style.css`：首屏布局、桌面与移动端适配。
- `css/blog.css`：博客内容、导航、阅读页、404 与移动端适配。
- `js/main.js`：本地时钟、星空、视差与动画生命周期。
- `js/loading.js`：加载幕布、资源就绪检测与超时放行。
- `js/blog.js`：移动导航、文章搜索、分类筛选、每页 6 篇加载更多、筛选 URL 与浏览器前进后退。
- `js/article.js`：阅读进度、当前章节目录提示、复制链接与失败反馈。
- `content/posts/*.json`：文章内容的唯一编辑入口，目前为空。
- `scripts/build-blog.mjs`：校验文章并生成阅读页、首页静态列表、`js/posts-data.js`、RSS、sitemap、robots 和 404。
- `scripts/check-blog.mjs`：在独立临时目录验证内容生成、转义、草稿排除和过期页面清理，不向网站添加测试文章。
- `assets/fonts/`：背景标题 `GUDU’s` 使用本地 Barlow Condensed Black。字体及 SIL Open Font License 均随网站提供，不依赖在线字体服务。

## 添加真实文章

在 `content/posts/` 新建一个 JSON 文件。下面仅为字段说明，不是网站内的示例文章；请替换成真实内容和发布日期：

```json
{
  "slug": "your-article-slug",
  "title": "文章标题",
  "excerpt": "用于首页与 RSS 的文章摘要。",
  "date": "2026-10-14",
  "category": "随笔",
  "tags": ["记录"],
  "draft": false,
  "sections": [
    {
      "id": "opening",
      "title": "章节标题",
      "blocks": [
        { "type": "paragraph", "text": "真实的文章正文。" }
      ]
    }
  ]
}
```

- `slug` 使用小写英文字母、数字和连字符，对应 `posts/your-article-slug.html`，应保持稳定。
- 日期使用有效的 `YYYY-MM-DD`；文章按日期倒序排列，相同日期按 slug 排序。阅读时长根据正文估算。
- 分类和标签可自行填写；筛选项会从实际文章生成。搜索匹配标题、摘要、分类和标签，可与分类同时使用。
- `sections` 至少包含一章；省略章节 `id` 时自动生成。章节 id 在文章内应唯一。
- `draft: true` 的文章不生成阅读页，也不出现在首页、归档、RSS 或站点地图中。它不是定时发布功能，准备好后改为 `false` 再构建。
- 所有正文按纯文本处理，不执行原始 HTML，也不解析 Markdown。内容块还支持下列格式：

```json
{ "type": "list", "ordered": false, "items": ["第一项", "第二项"] }
{ "type": "quote", "text": "引用文字" }
{ "type": "callout", "text": "提示内容" }
{ "type": "code", "language": "js", "code": "const greeting = 'hello';" }
```

写好后执行：

```sh
npm run build
npm run check
npm run dev
```

构建会同步首页列表、归档、文章上下篇、RSS 与站点地图。删除源文章或将其改为草稿后重新构建，对应的旧生成页也会移除；手写页面不会被清理。不要手工编辑 `posts/*.html`、`js/posts-data.js` 或首页 `posts` / `archive` 标记区域，下次构建会重新生成这些内容。

GitHub Pages 直接发布仓库内的静态文件，因此部署时需要一并提交源文章和生成结果。关闭 JavaScript 后，已发布的文章列表、归档和正文仍然可读。RSS 地址为 [gudu.blog/feed.xml](https://gudu.blog/feed.xml)。

## 黑洞视觉

黑洞采用内联 SVG 绘制：深黑圆心、冷白细轮廓、一条前景光轨，以及更淡的后方轨道与上方透镜弧线，整体保持 14° 斜向构图。轮廓只有局部微光，光轨两端逐渐隐去。稀疏低亮度星点与留白衬托标题，不叠加噪点纹理。这是一幅极简抽象插画，不进行实时物理光线模拟。

矢量图形在不同屏幕上保持清晰，默认可见，不依赖 WebGL 或备用位图。黑洞作为完整图层参与轻微鼠标视差，保持各部分的遮挡关系；鼠标停稳后停止逐帧绘制。遵循系统减少动态效果偏好，页面隐藏或离开首屏时暂停视差。移动端不拦截触摸滚动，关闭 JavaScript 时仍可显示黑洞和标题。

时钟采用访问者设备的本地时区，每秒读取真实时间；与视觉动画独立更新，返回页面时立即校时。

标题在首次展示时分层入场：背景英文浮现、中文沿水平边界揭开、橙色句点最后落位，总时长约 0.9 秒。英文、中文与时钟使用不同幅度的鼠标视差；移动端保留入场，系统减少动态效果偏好下直接显示最终排版。入场结束或离开页面后不重复播放。

开场加载页使用极简冷白轨道与橙色方点，等待字体就绪和页面绘制后淡出，再开始标题入场。动画为不定进度提示，不显示虚构百分比；正常情况下至少展示 0.6 秒，淡出用时 0.42 秒，最迟在 4 秒时放行。关闭 JavaScript 时直接显示页面；资源失败、后台切换和减少动态效果偏好均有对应处理。

## 检查

```sh
npm run check
```

检查包含 JavaScript 语法、生成文件与文章源的一致性，以及生成器的自动化测试。提示生成文件过期时，先执行 `npm run build`。测试内容只存在于临时目录中。
